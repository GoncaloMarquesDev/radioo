# 🎧 Radioo

Radioo is a modern web application that allows users to discover, search, and listen to radio stations from around the world through a clean and intuitive interface.

The application features a global audio player, enabling continuous playback while users browse and explore new stations. Users can easily search for radio stations, manage their favorites, and enjoy a smooth listening experience across devices.

Built with a mobile-first approach, Radioo focuses on performance and user experience, incorporating global state management, asynchronous data handling, and responsive design to ensure a seamless user experience.

## ⚡ Features
🔍 Real-time radio station search
🎧 Global audio player (continuous playback across the app)
⭐ Add and manage favorite stations (saved locally)
📱 Fully responsive, mobile-first interface
⚡ Global state management (Context API)
⏳ Loading states for async operations
❌ Error handling for API requests

## 🛠️ Tech Stack
React (Hooks, Functional Components) with TypeScript(static typing)
JavaScript (ES6+)
REST API Integration (fetch / async-await)
Context API (global state management)
Local storage for data persistence
Component-based architecture (reusable components)
CSS / SASS (responsive & mobile-first design)
Vercel (deployment)
Git & GitHub (version control)
